# Landing Page - Fonoaudiologia Cláudia Fons

Este é o repositório da Landing Page profissional desenvolvida para a clínica de Fonoaudiologia da Dra. Cláudia Fons.

## 🚀 Sobre o Projeto

A página foi criada com o objetivo de apresentar os serviços fonoaudiológicos, tratamentos oferecidos e facilitar o contato com os pacientes. O design é moderno, responsivo e focado na experiência do usuário (UX).

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica do site.
- **CSS3**: Estilização personalizada, layouts flexíveis e animações (Vanilla CSS).
- **Vanilla Javascript**: Para interatividade e funcionalidades dinâmicas.

## 📱 Funcionalidades

- Design Responsivo (Adaptável a celulares, tablets e computadores).
- Seções de Especialidades e Tratamentos.
- Botões de chamada para ação (CTA) integrados ao WhatsApp.
- Rodapé com links para redes sociais e informações de contato.

## 📄 Como visualizar

Para visualizar o projeto localmente:
1. Clone o repositório: `git clone https://github.com/gustavocastanha44-lgtm/fonoclaudiafons.git`
2. Abra o arquivo `index.html` em seu navegador.
